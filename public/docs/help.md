このガイドは、TateSpun で縦書き原稿を書くための基本操作をまとめたものです。下に並ぶ見出しから、知りたい項目だけ読めます。

ヘルプは、編集画面のメニューにある「ヘルプ」ボタン（画面上部の「？」マークからも開けます）でいつでも表示できます。

## ルビ（振り仮名）

`｜` と `《》` を使って、漢字にルビを振れます。

```
｜漢字《かんじ》
```

と入力すると、プレビューでは「漢字」の上（縦書きでは右）に「かんじ」と小さく表示されます。読みを付けたい語の直前に `｜` を置き、直後の `《　》` の中に読みを書いてください。

## 縦中横（たてちゅうよこ）

縦書きの行の中で、数字や短い英字を横並びのまま（正立させて）表示する組み方です。

**自動判定**

前後を数字で挟まれていない半角2桁の数字（例：`12`月`25`日）と、`!!` `!?` `?!` `??` のペアは、自動的に縦中横になります。

**明示記法 `[tate]…[/tate]`**

自動判定されない文字列（3桁以上の数字、英字を含む短い列など）を縦中横にしたいときは `[tate]` と `[/tate]` で挟みます。

```
用紙は[tate]A5[/tate]、西暦[tate]2026[/tate]年。
```

括弧内は8文字までが目安です（長すぎると潰れて読めません）。`[tate]` `[/tate]` 自体は表示されません。

## 改ページ

改ページの記法は `【改ページ】` です。`【改ページ】` は本文には表示されず、そこでページが区切られます。

`【改ページ】` は、**その行に続きの文字があるかどうか**で動作が変わります。使い方は次の3つです。

### 1. 改ページだけを書く

```
【改ページ】
```

その行でページを区切り、次の文章を新しいページから始めます。`【改ページ】` 自体は本文には表示されません。

### 2. 行の最後につける

```
章タイトル【改ページ】
```

その行の文章（例：章タイトル）を表示したあとでページを区切ります。見出しや短い文章の直後でページを変えたいときに使えます。`【改ページ】` 自体は表示されません。

### 3. 文章の途中に書く

```
これは【改ページ】という文字です
```

同じ行で `【改ページ】` のあとにも文章が続いている場合は、改ページ命令になりません。`【改ページ】` という文字としてそのまま表示されます。

（`＃改ページ` は使いません。改ページの記法は `【改ページ】` です。）

## 文章チェック β

入力中の文章から、括弧の閉じ忘れや句読点の重複など「確認した方がよい箇所」を、TateSpun が赤い波線でお知らせする機能です（β版）。編集画面の下部で、いつでもオン／オフを切り替えられます（初期状態はオン。設定はこの端末に保存され、本文には記録されません）。

### 赤い波線について

赤い波線は「文章が間違っている」と断定するものではありません。小説・創作では意図的な表現もあるため、内容を確認したうえで、最終的には作者ご自身がご判断ください。TateSpun が文章を自動で書き換えることはありません。

### 現在チェックするもの

- 括弧の対応（`「」` `『』` `（）` `［］` `【】` の閉じ忘れ・対応ミス）
- 明らかな句読点の重複（`。。` `、、`）
- TateSpun 記法の一部の入力ミス（`[tate]…[/tate]` の崩れ、`｜…《…》` ルビ記法の崩れ）

`！？` や `……`、`――` などは、意図的に使われることが多いため確認候補にしません。

### プライバシー

文章チェック β の判定処理は、すべてお使いのブラウザの中で行われます。この機能のために本文を外部の AI／API へ送信することはありません。
（TateSpun 全体では、クラウド保存やログインなど一部の機能で通信を行います。「文章チェック β の判定のために通信しない」という意味です。）

### 出力について

赤い波線は編集画面だけの補助表示です。プレビュー・JPG・PDF には出力されず、本文そのものにも書き込まれません。

### オン／オフ

文章チェック β は、編集画面下部のチェックボックスからいつでもオン／オフできます。オフにすると赤い波線は完全に非表示になります。

## 印刷設定

設定パネルの「① ページ設定」から、印刷・PDF出力時のレイアウトを調整できます。

- **用紙サイズ・余白**: 出力するページのサイズと余白を指定します。
- **文字数・行数**: 1ページあたりの文字数と行数を設定し、ページ割りを調整します。
- **フォント**: 縦書き本文に使用するフォントを選択します。

設定を変更すると、プレビューにその場で反映されます。印刷する際は、ブラウザの印刷機能（Ctrl+P / Cmd+P）を使用してください。

## プレビューを移動する

プレビューを拡大しているときは、プレビュー上をドラッグ（マウスで押したまま動かす／画面では指でなぞる）すると、見たい位置へスムーズに移動できます。

拡大・縮小は、プレビュー右上の「＋ / －」ボタンや「100%」ボタン、キーボードショートカット（Ctrl / Cmd ＋ ＋ / － / 0）で調整できます。

![プレビュー上をドラッグして表示位置を動かし、＋／－で拡大・縮小する操作アニメーション](/help/preview-drag.gif)

## プレビューの点線（仕上がり線）について

プレビューの各ページに表示される灰色の点線は「仕上がり線」です。印刷・製本で断裁される位置の目安を示します。

- 点線とその内側が、本として実際に残る範囲です。
- 点線の外側（約3mm）は「塗り足し」で、断裁時に切り落とされます。背景や画像をページの端まで載せたいときは、この外側までしっかり伸ばしておきます。
- この点線はプレビューの目安表示です。JPG・PDF の書き出しには出力されません（書き出しでは「仕上がりサイズ」「断ち落としサイズ」「入稿用フルサイズ」から選べます）。

ノンブル（ページ番号）や柱は、この仕上がり線の内側に収まるように配置されます。

## ページの複数選択

プレビュー上の各ページに表示される［選択］にチェックを入れると、書き出しなどの対象ページを選べます。

最初のページの［選択］にチェックを入れたあと、`Shift` キーを押しながら離れたページの［選択］をクリックすると、最初に選択したページからクリックしたページまでをまとめて範囲選択できます。

```
1ページ目を選択 → Shiftを押しながら5ページ目を選択 → 1〜5ページがまとめて選択される
```

## 奥付

編集画面の上部にある「📖 奥付・目次」ボタンから、奥付・目次を作成できます。奥付には「奥付（縦）」と「奥付（横）」の2種類があります。

再編集も同じ「📖 奥付・目次」ボタンから行えます。

### 奥付（縦）

「奥付（縦）」は、通常の本文ページとして作成されます。フォームに入力して本文の末尾へ挿入すると、あとは縦書き本文として自由に編集できます。本文と同じ縦書きで組まれ、本文のページ割り・ノンブルにも通常どおり参加します。

### 奥付（横）

「奥付（横）」は、本文とは独立した横書き専用ページとして作成されます。用紙サイズ・余白は本文と同じものが使われます（本文が縦書き A5 なら、奥付も同じ A5 の紙）。「奥付（横）」タブの「奥付（横）の設定を開く」から、配置・テンプレート・項目・フォント・自由記述などを設定します。

### 選び方

- 縦書きの奥付にしたい → 「奥付（縦）」
- 横書きの独立した奥付ページにしたい → 「奥付（横）」

どちらかを強制するものではありません。作品に合う方を選んでください。

### 配置場所（奥付（横））

横書き奥付ページを、作品全体のどこへ入れるかを選べます。

- 「本文 ○ P目の後に配置」: 指定した本文ページの直後に奥付ページを入れます。長編でも、ページ数を直接入力できます。
- 「作品最終ページに配置」: 常に作品のいちばん最後に置きます（本文が増減しても末尾へ追従します）。

指定した本文ページが（編集で本文が短くなり）現在なくなっている場合は、指定値はそのまま保持したうえで、奥付を一時的に作品最終ページの後ろへ表示します。本文が再びそのページ数以上になれば、元の指定位置へ自動的に戻ります。

### 配置（奥付（横））

奥付ページ「内」での、奥付ブロックの位置を選べます。

- 左右: 左寄り / 中央寄せ / 右寄り
- 上下: 上部寄せ / 中央寄せ / 下部寄せ
- 「ノドを考慮する」: 綴じ側の余白を避けて配置します。
- 「天地の余白を考慮する」: 本文と同じ天地の余白の内側を基準に配置します。

配置はテンプレートとは独立しています。テンプレートを変更しても配置は維持されます。

### 本文への影響

「奥付（横）」を追加・移動しても、本文の文字数・改ページ・縦書き設定は変わりません。

### 制限（奥付（横））

- 横書き奥付は1ファイルにつき1ページのみ配置できます。
- 横書き奥付には縦書きのテキストや画像を入れられません（縦書きや画像が必要な場合は「奥付（縦）」を本文ページとして作成してください）。

### 項目名について（奥付（横））

初期状態では「書名」「著者名」「サークル名」「発行日」「印刷所」「連絡先」「発行者」が用意されています。

項目名そのものを変更できます。値も自由に入力できます。

- 例: 「書名」→「作品名」
- 例: 「連絡先」→「Website」
- 「＋ 項目を追加」で新しい項目（例: 「Special Thanks」「装丁」「使用フォント」）を増やせます

各項目は「表示」チェックで出す・出さないを切り替えられ、「↑」「↓」で並び替え、「削除」で消せます。項目を削除しても他の項目には影響しません。

### テンプレート

4種類から選べます。

- 標準（左に項目名・右に値）
- 中央（中央揃え）
- ミニマル（書名を主役に、余白を活かす）
- クラシック（罫線を使った情報整理型）

テンプレートを変更しても、入力済みの奥付情報（項目名・値・並び順・表示／非表示・フォント・自由記述）と配置は維持されます。

### 自由記述

奥付の下部に、無断転載についての注意書き・SNS／Web サイト・謝辞などを自由に書ける欄です。入力した文字はそのまま表示されます（HTML などは解釈されません）。

### ノンブル

本文でノンブル（ページ番号）を表示している場合、横書き奥付ページにも、実際の作品ページ順（物理ページ順）に沿った続きのページ番号が表示されます。奥付を本文の途中へ入れた場合、それ以降の本文ページの番号は1つずつ繰り下がります（本文の中身や改ページは変わりません）。本文のノンブルを非表示にしている場合は、奥付にも表示されません。柱は付きません。

### 書き出し（Preview・JPG・PDF）

奥付はプレビューに表示され、書き出しの対象になります。

- Preview: 奥付がオンなら、指定した位置（本文の何ページ後 / 作品末尾）に奥付ページが表示されます。
- JPG: 書き出しメニューの「奥付ページ（JPG）」から、奥付ページを画像として書き出せます。
- 全ページPDF: 奥付がオンなら、指定した位置に含まれます。
- 選択ページPDF: PDF出力画面で「奥付ページを含める」を選んだ場合のみ含まれます。選んだ場合、奥付は選択した本文ページの中での正しい相対位置に入ります（単純に末尾へ付けられるわけではありません）。

本文の縦書きページと横書きの奥付ページは、同じ PDF の中に並びます（同一ページ内での縦横混在ではありません）。

### 収まらないとき

奥付の内容が1ページに収まらない場合はプレビューに警告が出ます。β版では自動でのページ分割・文字の縮小・切り捨ては行いません。項目や自由記述を減らして調整してください。

## β版フィードバック（報告ボタン）

エディター上部の黄色い「報告」ボタンは、β期間中だけ表示されます。不具合・気になること・要望を送るための入口です。

### 気になる事

匿名で届く簡易フィードバックです。ログインもメールアドレスも不要です。思いついたことを書いて「匿名で送信する」を押すだけで届きます。記名を希望する場合は、本文の冒頭にお名前を入れてください。

必要に応じて画像を4枚まで添付できます。対応形式はJPEG・PNG・WebPです。送信前に、画像へ個人情報などが写っていないかご確認ください。添付した画像は1枚ずつ削除できます。本文が空でも、画像が1枚以上あれば送信できます。

### review

βテスター向けの確認用チェックリストです。問題なく確認できた項目にチェックしてください。未チェックは「不具合」という意味ではありません。reviewには画像を添付できません。

### 送信前の確認について

「気になる事」「review」どちらも、送信の前に「あなたが人間であること」の簡単な確認（チェックボックス1つ程度）が入ります。うまく確認できないときは、少し待つか、ページを再読み込みしてからもう一度お試しください。この確認は送信のたびに必要です。

## PSDファイルの挿入

画像挿入から、Photoshop の `.psd` ファイルを選ぶことができます。PSDファイルは挿入時に、元の縦横ピクセルサイズを保ったPNGへ変換され、原稿内の画像として配置されます。

※PSDファイルは、各ページの操作メニューの「このページに画像を挿入」から選択してください。PSDファイルのドラッグ＆ドロップによる挿入には対応していません。

※レイヤーを結合した状態（描画結果）が変換されます。RGBモードのPSDをご利用ください。

## TateSpunは画像挿入が可能！でも、画像はどこに保存される？

### A. この端末で使うとき

- 挿入した画像は、TateSpun がこの端末のブラウザに保存する作業データと一緒に保存され、作品にそのまま使われます。
- この端末内の画像には、下記「B」の**クラウド一時コピーの72時間タイマーはかかりません**。TateSpun 側がこの端末の画像を72時間後に削除することはありません。
- ただし、ブラウザのサイトデータ削除・別のブラウザ・別の端末・端末の故障や初期化などでは、この作業データを引き継げないことがあります。ブラウザ保存が永久に残ることを保証するものではありません。

### B. クラウド保存を使うとき（会員）

- 別の端末でも作品を復元できるよう、画像の**一時コピー**がクラウドへアップロードされます。
- β版では、このクラウド上の一時コピーの寿命は **72時間** です。
- 画像を含むクラウド保存に再度成功すると、期限はその時点から72時間に更新されます。
- Guest（未登録）の画像はクラウドへ同期されないため、この「72時間」の対象外です（そのぶん、別端末への持ち出しもできません）。

> **72時間で削除されるのは、クラウド上の一時コピーです。**
> 原稿本文や、この端末の画像を72時間後に削除するという意味ではありません。
> この端末で作業を続けるだけなら、72時間以内に何かをする必要はありません。

### 大切な原稿は、ときどきバックアップを

![原稿のバックアップをすすめる、カロードのイラスト](/help/backup-caroad.png)

ブラウザのデータ削除や端末トラブルに備えて、本文の控えや、PDF・JPG などの書き出しデータを、別の場所にも保存しておくと安心です。挿絵にした元画像も、お手元に保管しておくことをおすすめします。

### クラウド画像が期限切れになったら

別端末や別ブラウザなど元画像を持っていない環境では、期限切れ後のクラウド画像は復元できません。その場合は、画像をもう一度配置してください。元画像が手元のブラウザに残っていれば、そのまま使い続けられます。

### 画像に警告が表示された場合

期限切れ、または取得できない画像がある作品には警告が表示されます。

未解決の画像が残っている間は、画像が欠けた状態で完成データを作ってしまわないように、JPG・PDFなどの書き出しを停止します。

画像を再配置し、必要に応じて再度クラウド保存したあと、警告が解消されれば通常どおり書き出せます。

### 別端末でも使いたい場合

Memberで画像を含む作品をクラウド保存すると、72時間以内であれば、元画像を持っていない別ブラウザや別端末でも、クラウド上の画像から復元できます。

長期間空けて別端末から編集する場合は、元画像も手元に用意しておくことをおすすめします。

## キーボードショートカット

- `Ctrl` / `Cmd` + `S` ： 下書きの手動保存
- `Ctrl` / `Cmd` + `+` ： プレビュー拡大
- `Ctrl` / `Cmd` + `-` ： プレビュー縮小
- `Ctrl` / `Cmd` + `0` ： プレビュー倍率リセット（100%）
- `Ctrl` / `Cmd` + `Z` ： 元に戻す（Undo）
- `Ctrl` / `Cmd` + `Y` ： やり直す（Redo）
