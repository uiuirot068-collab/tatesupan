このエディタで縦書き原稿を書くための基本操作をまとめています。各項目の見出しから、必要なところだけ読めます。

## ルビ（振り仮名）

`｜` と `《》` を使って、漢字にルビを振れます。

```
｜漢字《かんじ》
```

と入力すると、プレビューでは「漢字」の上（縦書きでは右）に「かんじ」と小さく表示されます。読みを付けたい語の直前に `｜` を置き、直後の `《　》` の中に読みを書いてください。

## 縦中横（たてちゅうよこ）

縦書きの行の中で、数字や短い英字を横並びのまま（正立させて）表示する組み方です。

**自動判定**

前後を数字で挟まれていない半角2桁の数字（例：`12`月`25`日）と、`!!` `!?` `?!` `??` のペアは、自動的に縦中横になります。

**明示記法 `[tate]…[/tate]`**

自動判定されない文字列（3桁以上の数字、英字を含む短い列など）を縦中横にしたいときは `[tate]` と `[/tate]` で挟みます。

```
用紙は[tate]A5[/tate]、西暦[tate]2026[/tate]年。
```

括弧内は8文字までが目安です（長すぎると潰れて読めません）。`[tate]` `[/tate]` 自体は表示されません。

## 改ページ

改ページの記法は `【改ページ】` です。`【改ページ】` は本文には表示されず、そこでページが区切られます。

`【改ページ】` は、**その行に続きの文字があるかどうか**で動作が変わります。使い方は次の3つです。

### 1. 改ページだけを書く

```
【改ページ】
```

その行でページを区切り、次の文章を新しいページから始めます。`【改ページ】` 自体は本文には表示されません。

### 2. 行の最後につける

```
章タイトル【改ページ】
```

その行の文章（例：章タイトル）を表示したあとでページを区切ります。見出しや短い文章の直後でページを変えたいときに使えます。`【改ページ】` 自体は表示されません。

### 3. 文章の途中に書く

```
これは【改ページ】という文字です
```

同じ行で `【改ページ】` のあとにも文章が続いている場合は、改ページ命令になりません。`【改ページ】` という文字としてそのまま表示されます。

（`＃改ページ` は使いません。改ページの記法は `【改ページ】` です。）

## 文章チェック β

入力中の文章から、括弧の閉じ忘れや句読点の重複など「確認した方がよい箇所」を、TateSpun が赤い波線でお知らせする機能です（β版）。編集画面の下部で、いつでもオン／オフを切り替えられます（初期状態はオン。設定はこの端末に保存され、本文には記録されません）。

### 赤い波線について

赤い波線は「文章が間違っている」と断定するものではありません。小説・創作では意図的な表現もあるため、内容を確認したうえで、最終的には作者ご自身がご判断ください。TateSpun が文章を自動で書き換えることはありません。

### 現在チェックするもの

- 括弧の対応（`「」` `『』` `（）` `［］` `【】` の閉じ忘れ・対応ミス）
- 明らかな句読点の重複（`。。` `、、`）
- TateSpun 記法の一部の入力ミス（`[tate]…[/tate]` の崩れ、`｜…《…》` ルビ記法の崩れ）

`！？` や `……`、`――` などは、意図的に使われることが多いため確認候補にしません。

### プライバシー

文章チェック β の判定処理は、すべてお使いのブラウザの中で行われます。この機能のために本文を外部の AI／API へ送信することはありません。
（TateSpun 全体では、クラウド保存やログインなど一部の機能で通信を行います。「文章チェック β の判定のために通信しない」という意味です。）

### 出力について

赤い波線は編集画面だけの補助表示です。プレビュー・JPG・PDF には出力されず、本文そのものにも書き込まれません。

### オン／オフ

文章チェック β は、編集画面下部のチェックボックスからいつでもオン／オフできます。オフにすると赤い波線は完全に非表示になります。

## 印刷設定

画面右側の設定パネルから、印刷・PDF出力時のレイアウトを調整できます。

- **用紙サイズ・余白**: 出力するページのサイズと余白を指定します。
- **文字数・行数**: 1ページあたりの文字数と行数を設定し、ページ割りを調整します。
- **フォント**: 縦書き本文に使用するフォントを選択します。

設定を変更すると、プレビューにその場で反映されます。印刷する際は、ブラウザの印刷機能（Ctrl+P / Cmd+P）を使用してください。

## プレビューのパン（ドラッグ移動）

プレビュー画面を拡大しているときは、画面上をマウスでドラッグ（掴む）することで、自由な位置へスムーズにスクロール移動できます。

## PSDファイルの直接挿入

Photoshopの `.psd` ファイルを、そのままプレビューへドラッグ＆ドロップして挿入できます。挿入時に自動で高画質なPNGへ変換されます。

## ページの複数選択

プレビュー上の各ページに表示される［選択］にチェックを入れると、書き出しなどの対象ページを選べます。

最初のページの［選択］にチェックを入れたあと、`Shift` キーを押しながら離れたページの［選択］をクリックすると、最初に選択したページからクリックしたページまでをまとめて範囲選択できます。

```
1ページ目を選択 → Shiftを押しながら5ページ目を選択 → 1〜5ページがまとめて選択される
```

## キーボードショートカット

- `Ctrl` / `Cmd` + `S` ： 下書きの手動保存
- `Ctrl` / `Cmd` + `+` ： プレビュー拡大
- `Ctrl` / `Cmd` + `-` ： プレビュー縮小
- `Ctrl` / `Cmd` + `0` ： プレビュー倍率リセット（100%）
- `Ctrl` / `Cmd` + `Z` ： 元に戻す（Undo）
- `Ctrl` / `Cmd` + `Y` ： やり直す（Redo）
