## 1. 音読β（B4）

場所: 画面下の **▶ 見直し** → 一覧の3番目 **音読β**。

- [ ] 開いただけ・文字を打っただけでは、**勝手に読み上げない**。
- [ ] 文章の一部を選んで **選択範囲を読む** → 選んだ所だけ読む。何も選ばずに押すと、説明が出て読まない。
- [ ] カーソルを段落の中に置いて **現在の段落を読む** → その段落だけ読む。
- [ ] **全文を読む** → 最初から順番に読む。`｜宇宙《そら》` は「そら」と読み、`｜` や `《》` は読まない。
- [ ] **一時停止 → 再開** で続きから読む（スマホでは文の頭からやり直すことがあります。気づいたらメモ）。**停止** ですぐ止まり、その後は何も読まない。
- [ ] **速度** を 0.5／1.0／2.0 にして、はっきり違う。読んでいる途中で変えても、しばらくして反映される。
- [ ] 全文を読むを何度も押しても、声が **2重にならない**。
- [ ] 声を選べる場合（音声の欄）、選んだ声で読む。ページを再読み込みしても選択が残る。
- [ ] 「この端末の音声で読みます。原稿を外部へ送りません。」の文が、スマホでもスクロールしないで見える。
- [ ] **端末の声の状態を書いてください:** 使った端末・ブラウザ ______ ／ 最初に使われた声の名前 ______ ／ 「日本語の音声が見つかりません」と出た？ はい・いいえ
   - 出た場合: 文章は読まれず、案内だけが出ていればOKです（Windowsの設定で日本語の音声を追加すると読めます）。
   - 「オンライン音声」という名前の声は、自分で選ばないかぎり使われず、選ぶと「本文が送信される場合があります」の注意が出る。
- [ ] リズム確認として役に立つ？（とても／少し／あまり）: ______ ／ 足りないもの（例: 読んでいる所の色つけ）: ______

## 2. 描写語・修飾表現チェックβ（B5）

場所: **▶ 見直し** → 一覧の4番目 **描写語・修飾表現チェックβ**。

- [ ] ページを再読み込みしても、オン／オフと範囲（A・A+B・A+B+C）が残る。オフにすると印が全部消える。
