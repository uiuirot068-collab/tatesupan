# B5 描写語・修飾表現チェックβ — 仕様コーパス / 回帰コーパス

このファイルは **人が読める仕様** であり、同時に **自動回帰テストのデータ** です（`src/lib/descriptionCheck.test.ts` がこの表を読み取って解析結果と照合します）。行を足す・直すだけでテストに反映されます。Human の実原稿から作る A / B / C / 対象外 / 迷う の判定は、同じ形式でこの表に追記してください。

## 区分の意味（仕様）

| 区分 | 意味 |
|---|---|
| **A** | 直接の形容・状態・評価・様子の説明（いちばん絞った候補）。例: 美しい／静かな／ゆっくりと |
| **B** | 描写として働きうる連体・連用の修飾（すでに情景描写として機能している可能性あり）。例: 泣いている〔少女〕／夢のような／笑いながら |
| **C** | 時間・場所・用途・識別などの修飾。例: 昨日の／机の上の／料理用の／田中さんの |
| **対象外** | 拾ってはいけない（印の箇所を候補にしてはならない） |
| **迷う** | 人でも判断が割れる。テストでは検証せず、結果を観察するだけ |

A/B/C は文章の良し悪しの順位ではなく、**拾う範囲の広さ** です。マーカーは同じ黄色で、区分は詳細に表示します。

## 表の読み方

- `印の箇所`: A/B/C は「その区分の候補としてこの文字列が拾われること」、対象外は「この文字列が（どの区分でも）拾われないこと」。
- `状態`: `期待` = 現在の解析器がこのとおりに動くことをテストで固定する ／ `既知の取りこぼし` = 仕様上は拾うべきだが現在の解析器は拾えない（限界として記録。テストは失敗させず、結果だけ集計する）。
- **開発セット**（D-）は解析器を作りながら見た文です。**未知文セット**（U-）は解析器を実行する前に書いた文で、初回の結果を `B5_IMPLEMENTATION_RESULT.md` に **そのまま** 記録しています（後から合わせ込んだ行は「状態」で区別）。
