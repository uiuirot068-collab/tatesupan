# TateSpun v2 Human E2E Editor (development only)

From the repository root, run:

`npm.cmd exec -- vite --config typesetting-v2/tools/human-e2e-editor/vite.config.ts`

Open `http://127.0.0.1:5173/`. Edit the Manuscript textarea; Preview updates from the real v2 Canonical document. Use **Update Preview** after changing settings and **Export v2 Vector PDF** for the real Publication PDF.
