# TSP-SAFE-006 本棚を spuntales.net にまとめる（2026-10-19）

なつおの決定（10/19）: 本棚は spuntales.net/tatespun/ のものを使う。tatespun.pages.dev は spuntales.net の配信元なので消せないが、ブラウザは住所ごとに別の本棚を持つため、そこで書いた作品は spuntales.net に出てこない。黙って転送すると作品が見えなくなるので、作品があれば移してから案内する（なつお「はいこのやり方で進めなさい」）。

## したこと

- tatespun.pages.dev で開いたとき
  - 本棚（とゴミ箱）に移す作品が無ければ、同じページの spuntales.net へそのまま移る。使い方ガイドと空の作品は数えない。
  - 作品があれば、本棚のページの上に「本棚の場所が変わりました」と出し、「作品を spuntales.net に移す」「ファイルに書き出す」を置く。ほかのページ（エディタなど）は左下に小さく「本棚は spuntales.net に移りました（作品を移す）」。
  - 「作品を spuntales.net に移す」: spuntales.net の新しいタブを開き、作品・ゴミ箱・挿絵と表紙の画像を渡す（ブラウザのタブどうしの受け渡し。相手の住所を確かめてから受け取る）。終わると両方のタブに「n作品を移しました」。もとの作品は消さない。
  - 移したあと、ここで何も書いていなければ、次からは spuntales.net へそのまま移る。ここで書きなおすと、また案内が出る。`?stay=1` を付けると移らずに開ける（中を確かめる用）。
  - 「ファイルに書き出す」: tatespun-bookshelf-年月日.json を保存し、spuntales.net で「ファイルから読み込む」で入れる（新しいタブが開けないとき、返事がないとき用）。
- spuntales.net で受け取るとき
  - 作品は空いている番号で入る（spuntales.net の作品を上書きしない）。最後に書いた日はそのまま。ゴミ箱の作品はゴミ箱に、ゴミ箱に入れた日のまま入る。
  - 同じ作品をもう一度移しても増えない（「もう移してありました」）。
  - 本棚の上限（60作品）を超えるときは1つも移さず、「いっぱいのため移せませんでした」。
  - 短編集はもとの作品を新しい番号で指しなおす。
  - クラウドに保存した作品は、保存先とのつながりごと移す。spuntales.net で同じクラウドの作品をもう開いていたら、ふつうの作品として入れる（1つのクラウド作品の控えが2つにならないように）。
- PC で確かめる用: 開発用の起動のときだけ、NEXT_PUBLIC_TATESPUN_OLD_ORIGIN / NEXT_PUBLIC_TATESPUN_HOME_ORIGIN で2つの住所を置きかえられる（公開用の作り方では必ず本物の住所）。

## 移さないもの（理由）

- エディタの作業の記録（作業カウンターなど、ブラウザの別の保存場所にあるもの）: 作品の中身ではなく、無くても作品は開ける。
- 使い方ガイド・空の作品: spuntales.net にもある／中身がない。

## 確かめ

- npm run test:all 3926 合格・不合格0（新しく src/lib/bookshelfMove.test.ts 11件）。tsc・eslint は前からある分だけ。
- 画面: 2つの住所を手元で再現して（https の tatespun.pages.dev と spuntales.net をこの PC に向けて）、空の本棚の移動、案内、タブでの移動、2回目、移したあとの移動、書きなおしたあとの案内、ファイルでの移動、まちがったファイル、スマホ幅、暗い画面を確かめた。
