# テストの不合格の扱い（TSP-IMPROVE-002 / P0-5）

2026-10-14、master 3879f28 からの作業。全部のテストは `npm run test:all` で流す（`scripts/test-all.mjs`）。

- 落ちてよいテストは `ci/known-failures.json` に、分類と理由つきで載せる。ここに無いテストが落ちたら `test:all` は失敗になる。
- 一覧に載っているのに合格したテストは、実行のたびに「一覧から外してください」と表示される。
- 見本ファイル（`typesetting-v2/qa/` の PDF・JPG・ZIP など）は、テストを流しても書きかわらない。作りなおす時だけ `UPDATE_QA_ARTIFACTS=1` をつける（`tests/setup/redirectQaArtifacts.ts`）。
- 速さを測る設定（`scripts/perf`、`tests/performance`）は流さない。
