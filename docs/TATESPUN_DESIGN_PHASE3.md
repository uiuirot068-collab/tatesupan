## システム（Phase 3 "folio"）

- **ラベル:** 英字の小さな大文字を墨ベタに白抜き（ダークは反転）。
- **見出し:** 明朝。広い画面ではセクション名を縦組みにして、点線で本文と区切る。
- **数字:** 手順・章は大きな金色の数字。線でつなぐ。
- **ボタン:** 主役はぼかさない影（ずらした板）の塗りボタン1つ。副はアウトライン、補助は文字リンク。
- **面:** 表紙と締めの帯だけ墨の全幅。本棚と図版は内側に細い金の罫がある台紙。
- **動き:** ホバーの 150–250 ms の移動（3 px 以内）と色の変化だけ。勝手に動くものはない。
  `prefers-reduced-motion` で止まる。本文入力欄のまわりには何も加えていない。

## 保持したもの

キーカラー、全機能、保存データと形式、IME、WINDOWED、undo / redo、autosave、restore、
検索・置換、プレビュー、書き出し、Core、既存作品との互換性。HOW TO の本文・`data-copy-id`・
アンカー・ヘルプ / 報告 / 支援 / 更新ログはすべてそのまま（文章は削っていない）。
E2E が使う「最初のボタン＝新規作成」の契約（`[data-home-onboarding-actions]` /
`[data-home-returning-actions]`）も保持。
