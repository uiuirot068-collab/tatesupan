3. 実装 → テスト(CST: `npm test`・typecheck・lint・build / TSP: `npm test`・必要なら `npm run build:basepath`)→ 画面確認。
4. 更新履歴に追加、このロードマップと STATUS を更新。
5. 「push してよいか」を確認 → OK後に作業ブランチだけ push → なつおPCの localhost で Human QA(Remote Control で準備、項目は「1 OK」形式)。
