# CST-PORT-012 3Dプレビュー（COLUMNSTAND → TateSpun）

移植ロードマップ候補4（棚卸し B4）。
元: columnstand `chatgpt/editor-v3-2-compact` 478d135 の本文3Dプレビュー（`EditorBook3D` ほか）。土台: TateSpun master 61eec0e（表紙 CST-PORT-011 入り）。

## 入口
- プレビュー上部の「1P / 見開き / 3D」で「3D」。戻るときは 1P か 見開き。
- 3D の間はプレビューの拡大・縮小ボタンは使えない（3D 側に拡大・縮小がある）。

## できること（CST と同じ）
- 閉・半・開（開き具合）、表・背・裏（向き）、回転・傾き、拡大・縮小、正面に戻す。ドラッグでも回せる（スマホは横方向だけ）。
- 製本方式（中綴じ / 平綴じ）。最初はページ数で決まる（64P以下は中綴じ）。作品には保存しない。
- ノド注意範囲（ピンク）。製本後に見づらくなりそうな幅の目安。クリックで説明、「次からこの説明を表示しない」あり。表示の入り切りと説明の有無はこのブラウザに記憶。
- 厚み: 表紙で背幅を入れていればその値、なければページ数から目安（1枚0.09mm＋表紙0.5mm）。ページ数に対して背幅が大きすぎる・小さすぎるときは注意を出す（止めない）。
- ページ番号を入れる・前／次で、そのページの見開きを開いた状態で表示（3D の間は見開き単位で動く）。

## TateSpun での作り方（CST との違い）
- 本文: TateSpun のページは縦書き組版の DOM が重いので、3D の中でページを組まない。
  プレビューに出ているページを、JPG / PDF 書き出しと同じ撮り方（`capturePageToCanvas`）で写し、
  仕上がり線で切った画像（長辺1100px）を3Dに貼る（`src/utils/book3dCapture.ts`）。
  ノドの曲がりの細片はすべて同じ画像を使う。写すのは開いているときの2ページだけ、閉じているときは0ページ。
- 書き換えたときは同じ2ページを撮り直す（約0.35秒待ってから）。撮り直しが終わるまで前の画像を出したまま。
- 3D は通常のプレビューの上に重ねて表示し、通常のプレビューは下で開いたまま（ページ移動と撮影に使う）。3D の間はページ番号がスクロールに引っぱられないようにした。
- 表紙・裏表紙・背: 表紙画面・表紙の書き出しと同じ描画命令（`buildCoverFacePlan` / `buildCoverSpreadPlan`）で描いて、仕上がりで切った画像を貼る（`useBook3DCoverTextures`）。「反映」した面だけ。未反映の面は「表紙未設定 / 本文 NP の仮冊子」。
- いつも右綴じ（背は表紙の右）。見開きは通常のプレビューと同じ組（1P は単独、2-3、4-5…、目次・奥付も含む）で、奇数ページが左、偶数ページが右。
- CST の「ノドを調整する」ボタン（ページ設定のノドへ飛ぶ）は入れていない。説明文は CST と同じ「ページ設定の『ノド』の数値を大きくしてください」。

## 既知の残課題
- 撮影は通常のプレビューの見た目そのもの。フォントの読み込み前に撮ると、そのときの字形で写る（書き換えれば撮り直す）。
- 「ノドを調整する」ボタンは未移植。
- 長いページ移動の直後は、画像ができるまで白いページ（細い罫）を出す。
