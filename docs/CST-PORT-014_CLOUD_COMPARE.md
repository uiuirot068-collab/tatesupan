# CST-PORT-014 クラウドの新旧比較（COLUMNSTAND → TateSpun）

移植ロードマップ候補6（棚卸し B5）。データベースの変更なし。
元: columnstand `chatgpt/editor-v3-2-compact` 297c617 `ColumnEditorShell.tsx`（作品を開くとき、端末版よりクラウド版が新しければ `window.confirm` で「クラウド版を開く／この端末版を開く（クラウド自動保存は停止）」）。土台: TateSpun master 2e7e6a7。

## TateSpun での食い違いの起き方
- COLUMNSTAND は1つの作品を端末とクラウドの両方に持ち、クラウドへ自動保存する。だから「開くとき」に新旧を比べる。
- TateSpun はクラウド作品を開くといつもクラウドから読み、クラウドへは「クラウドに保存」を押したときだけ書く。開くときに食い違いは起きない。
- 起きるのは「この画面で開いた（または保存した）あとに、別の端末やタブで同じ作品がクラウドに保存された」とき。これまでは「クラウドに保存」で新しい方を黙って上書きしていた。
- そこで比べる時点を「クラウドに保存」の直前にした。

## 中身
- この画面が最後に読んだ・保存したクラウド版の `updated_at` を覚えておく（開いたとき・保存したときに更新、端末の作品を開いたら消す）。
- 「クラウドに保存」（既にクラウドにある作品のとき）で、まずクラウドの今の版を読む。`updated_at` が覚えている時刻より新しければ確認画面を出して保存を止める。
  - 時刻はデータベースが付けるもの（`docs/supabase/migrations/20260912000000_projects_updated_at_trigger.sql`）。端末の時計は使わない。
  - クラウドが読めないときは、これまでどおり保存する（確認が保存を妨げない）。
- 確認画面「クラウド版の方が新しい原稿です」: この画面の版／クラウド版を左右に並べ、題名・文字数・時刻を出す。
  - 「この画面の版で上書き保存」… そのまま保存（挿絵の同期も今までどおり）。
  - 「クラウド版を開く」… クラウド版に入れ替える。この画面の版は捨てない: 端末の作品からクラウドに保存していた場合はその作品に残っている（自動保存を書き切ってから入れ替え）。クラウドから開いていた場合は、本棚に新しい作品「{題名}（この端末の控え）」として残す。
  - 「やめる」… 何もしない。
- CST の「クラウド自動保存を停止」は TateSpun に自動保存が無いので無い。
