# TSP-DEMO-001 — おためしデモをスマホで迷わず触れるように

きっかけ: SPN-RETEST-001（初見50人の再テスト）で、TateSpunの体験デモがスマホで見づらく15人が迷った。

## 見つかった点 → 直したこと
| 見つかった点 | 直したこと |
| --- | --- |
| 案内の吹き出しが画面やツールバーを隠す | スマホでは案内の高さを画面の約4割までに抑え、指す相手がないときは画面の下に置く。「案内をたたむ」で右下の小さなボタンにしまえる（「案内を開く」で戻る）。本文／プレビューの切り替えなど、画面が変わるタップのあとに位置を置き直す。 |
| プレビューが50%表示で読めない | デモのスマホでは、プレビューを1ページずつ（1P）画面幅いっぱいで開く。保存されている「1P／見開き」の選択は書き換えない（ボタンを押せばその選択に戻る）。スマホの拡大率の表示を実際の大きさに合わせ（最小100%）、最初の「＋」で本当に大きくなるようにした（デモ以外のスマホのプレビューも同じ）。 |
| 「ノンブル・柱」などの用語に説明がない | 該当するステップに、ことばの説明（ノンブル・柱・段組・奥付・ルビ・縦中横）を罫線の下に添えた。既存の文言は変えていない。 |
| 「デモを終了」を押すとデモ全体から出てしまう | 押すと一度だけ確認（「デモを続ける」／「終了する」）。案内だけ隠したい人向けに「案内をたたむ」を案内する一文を添えた。 |
