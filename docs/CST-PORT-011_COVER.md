# CST-PORT-011 表紙（COLUMNSTAND → TateSpun）

移植ロードマップ候補3（棚卸し B2、テンプレートなし含む）。
元: columnstand `chatgpt/editor-v3-2-compact` 478d135 の表紙機能。土台: TateSpun master 6a2c217。

## 入口
- エディターの「▶オプション」→ 先頭の「表紙」→「表紙を開く」。
- プレビューの「書き出し ▾」（スマホは共通の書き出しシート）→「表紙（JPG / PDF）」で書き出し画面。

## データ
- `PageSettings.cover`（形は CST の `CoverSettings` と同じ）。作品の設定と一緒に保存（端末・クラウドとも設定JSONの中。DBの形は変えていない）。
- 新しい作品に前の作品の表紙を持ち越さない（localStorage には表紙を書かない）。合本にも引き継がない。
- 表紙に敷く画像は本文の画像と同じ IndexedDB `images` に `cover-front-…` / `cover-back-…` のIDで保存。本文の画像管理とは別扱い。
- 表紙の編集では本文の組版・プレビューを作り直さない（レイアウトには表紙を除いた設定を渡す）。

## 描き方（作り直した部分）
CST は HTML/CSS を画像化していたが、TateSpun では V2 の PDF 生成に合わせ、
「描画命令の一覧（plan）」を純粋な関数で作り、Canvas 2D の1つの描画器でプレビューと書き出しの両方を描く。

- `src/lib/cover/coverPaint.ts` … 設定と寸法から plan を作る（テストあり）。基準は1面の幅 308px（CST の CSS 値をそのまま使える）。
- `src/lib/cover/coverCanvas.ts` … plan を Canvas に描く。フォント読み込み待ち・文字幅の計測。
- 縦書き（縦柱・背文字）は1字ずつ置く。2桁数字・`[tate]…[/tate]` は縦中横、英数字と「ー〜」は90°回転、句読点・括弧は縦書き用の字形（本文と同じ `verticalGlyphMap`）。
- TateSpun は常に右綴じなので、見開きは左から [表紙][背][裏表紙]。背文字は背の中央に1本の縦列（タイトル → 巻数 → 著者名）。

## 書き出し
| 内容 | 条件 | ファイル |
|---|---|---|
| 表紙・裏表紙を別々に（おすすめ） | 「反映」した面だけ | `{名前}_front` / `{名前}_back`（2つならZIP） |
| 表紙のみ | 表紙を反映済み | `{名前}_front` |
| 背表紙込みの見開き | 両面反映済み＋背幅 > 0 | `{名前}_cover_spread` |

- JPG / PDF、350dpi、RGB。1面は天地左右3mmの塗り足し込み。見開きは天地・小口のみ3mm（背との接合面は塗り足しなし）。
- 端末の上限（1600万画素）を超える大きさでは dpi を自動で下げる。
- Web閲覧用の用紙では本文と同じく PDF は選べない。
- 点線のガイドは書き出さない。

## CST との違い（意図したもの）
- 「中央配置」の画像は 350dpi での原寸で置く（大きすぎるときだけ縮める）。CST は画面上の CSS px 基準だった。
- 模様の「回転」はすべての模様で実際に回転させる。
- 背表紙の見出し番号は「04 背表紙」（CST は「03」が2つあった）。
- 3Dプレビュー（候補4）と確認用PDF（候補5）は別の回。

## 既知の残課題
- 表紙画像はクラウドに上がらない（設定は上がる）。別の端末では「この端末に保存されていません」と出る（候補22のクラウド画像でまとめて扱う）。
- 画像を差し替えたとき、前の画像は IndexedDB に残す（消さない安全側）。
- フォントの字幅がブラウザの CSS と少し違うため、CST の画面と1px前後ずれることがある。
